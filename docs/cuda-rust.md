# CUDA Rust

Reference for exploring Rust as an additional GPU-kernel development path in `gpu-playground`.

## NVIDIA CUDA Rust

- NVIDIA Developer Blog: [Introducing CUDA Rust: Two Tracks for Writing GPU Kernels](https://developer.nvidia.com/blog/introducing-cuda-rust-two-tracks-for-writing-gpu-kernels/)

The article describes NVIDIA's two CUDA Rust tracks for writing GPU kernels and is a useful starting point for future Rust/CUDA experiments alongside the existing C++/CUDA implementations in this repository.
