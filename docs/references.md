NVIDIA is exploring Rust as another path for GPU kernel development:

- [Introducing CUDA Rust: Two Tracks for Writing GPU Kernels](https://developer.nvidia.com/blog/introducing-cuda-rust-two-tracks-for-writing-gpu-kernels/)
  — NVIDIA Developer Blog. A starting point for future Rust/CUDA experiments
  alongside the existing C++/CUDA implementations.
